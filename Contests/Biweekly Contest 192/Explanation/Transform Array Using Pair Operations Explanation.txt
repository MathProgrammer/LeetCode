Notice that the operation leaves the sum of the array invariant. 

Sum before = S 
Sum after = S + A[i] - x + A[j] + x 

It is clearly not possible if the source and target arrays have different sums. 

If they have the same sum, it is always possble. 

We can simply fix the first element of the array 

S[1] and apply the operations to all other elements 

(S[1], S[2]) 
(S[1], S[3]) 
. 
. 
.
(S[1], S[n]) 

If (S[2, n]) = T{2, n}

Then S[1] = T[1] because the sum of both arrays is the same at every step. 

-----

class Solution {
public:
    bool canTransform(vector<int>& source, vector<int>& target) 
    {
        long long source_sum = 0, target_sum = 0;
        for(int i = 0; i < source.size(); i++)
        {
            source_sum += source[i]; 
            target_sum += target[i];
        }

        return (source_sum == target_sum);
    }
};
