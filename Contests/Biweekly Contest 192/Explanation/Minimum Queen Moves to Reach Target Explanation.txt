It will never take the queen more than 2 moves to reach from 
one cell to another. 

In one move the queen can go to the target row and in another the target column. 

We only have to check the special case where it can be done in fewer moves. 

If it's possible in one diagonal move. 
(The difference between the rows and columns have to be equal). 

If it's already in the target cell, the answer is 0. 

-----

class Solution {
public:
    int minQueenMoves(vector<int>& source, vector<int>& target) 
    {
        int answer = 2; 
        int row_difference = abs(source[0] - target[0]);
        int column_difference = abs(source[1] - target[1]);
        if(row_difference == column_difference || row_difference == 0 || column_difference == 0)
        {
            answer = 1;
        }

        if(row_difference == 0 && column_difference == 0)
        {
            answer = 0;
        }

        return answer;
    }
};
